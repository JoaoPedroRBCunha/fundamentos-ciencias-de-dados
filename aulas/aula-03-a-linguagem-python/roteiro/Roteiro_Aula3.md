## Bloco 2 — O que é Python e por que usamos | 0:20 – 1:00

Python é uma linguagem de programação criada em 1991. Ela foi projetada para ser simples de ler e escrever, o que a torna ideal para quem está começando.

No mundo da Ciência de Dados, Python é a linguagem mais usada. Bibliotecas como Pandas, NumPy e Scikit-learn permitem analisar dados, criar visualizações e aplicar modelos de machine learning com poucas linhas de código.

Em resumo: Python é a ferramenta que vai nos permitir executar tudo o que vimos nas aulas anteriores.

---

## Bloco 3 — Instalando o Python | 1:00 – 2:00

Vamos instalar o Python. Abra o seu navegador e acesse python.org.

No menu superior, clique em Downloads. O site vai detectar automaticamente que você está no Windows e vai sugerir a versão mais recente. Clique no botão de download.

Quando o instalador abrir, preste atenção: antes de clicar em qualquer coisa, marque a opção que diz Add Python to PATH. Essa opção fica na parte inferior da janela. Ela é essencial para que o Windows reconheça o Python em qualquer lugar do sistema.

Com a opção marcada, clique em Install Now e aguarde a instalação terminar.

---

## Bloco 4 — Instalando o VSCode | 2:00 – 2:45

Agora vamos instalar o VSCode, que é o editor de código que vamos usar.

Acesse code.visualstudio.com. Clique no botão Download for Windows. O download vai iniciar automaticamente.

Abra o instalador, aceite os termos e avance até o final. Na tela de opções adicionais, marque a opção Adicionar ao PATH e a opção Abrir com Code para arquivos e pastas. Depois clique em Instalar e aguarde.

---

## Bloco 5 — Configurando a extensão do Python no VSCode | 2:45 – 3:30

Com o VSCode instalado, abra o programa. Agora vamos instalar a extensão oficial do Python.

No menu lateral esquerdo, clique no ícone de quatro quadrados. Esse é o painel de extensões. Na barra de busca, digite Python.

O primeiro resultado é a extensão oficial da Microsoft. Clique em Install.

Essa extensão é o que permite ao VSCode reconhecer arquivos Python, destacar a sintaxe e rodar o código direto pelo editor.

---

## Bloco 6 — Primeiro código | 3:30 – 4:40

Agora vamos validar que tudo está funcionando criando o primeiro arquivo Python.

No VSCode, vá em File, depois New File. Salve o arquivo com o nome hello.py. A extensão .py é o que identifica um arquivo Python.

Dentro do arquivo, digite exatamente isso: print, abre parêntese, aspas, Olá Ciência de Dados, fecha aspas, fecha parêntese.

Para rodar, clique no botão de play no canto superior direito, ou abra o terminal integrado com Control mais acento grave e digite: python hello.py

Se aparecer Olá, Ciência de Dados no terminal, o ambiente está configurado e funcionando corretamente.

Pronto. Python instalado, VSCode configurado, extensão ativa e primeiro código rodando.

Com esse ambiente configurado você tem tudo o que precisa para começar a trabalhar com dados. Esse foi o último vídeo do módulo. Bons estudos.
