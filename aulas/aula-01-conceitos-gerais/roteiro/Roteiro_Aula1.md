# Roteiro — Aula 1: Conceitos Gerais sobre Ciência de Dados

---

## Bloco 1 — Abertura | 0:00 – 0:20

Olá! Nessa aula você vai entender o que é Ciência de Dados, para que ela serve e onde ela está sendo aplicada no mundo real. São conceitos fundamentais para qualquer pessoa que queira trabalhar com dados. Vamos começar.

---

## Bloco 2 — O que é Ciência de Dados? | 0:20 – 1:30

Ciência de Dados é uma área interdisciplinar. Ela combina três pilares: estatística, programação e conhecimento de negócio.

O objetivo é simples: extrair informações úteis a partir de grandes volumes de dados para apoiar a tomada de decisão.

Pensa assim: empresas acumulam dados o tempo todo. Vendas, cliques, cadastros, reclamações. A Ciência de Dados é o que transforma esse volume de informação bruta em algo que faz sentido e gera valor.

---

## Bloco 3 — Dado, Informação e Conhecimento | 1:30 – 2:30

Antes de continuar, preciso diferenciar três conceitos que costumam ser confundidos.

Dado é o registro bruto. Um número, uma data, um nome. Sozinho, ele não diz nada. Por exemplo: o número 47.

Informação é o dado com contexto. 47 clientes cancelaram o serviço em março. Agora faz sentido.

Conhecimento é quando você interpreta essa informação e age sobre ela. Os cancelamentos subiram 30% após a mudança de preço, então precisamos revisar nossa política comercial.

Esse fluxo, dado, informação, conhecimento, é a base de qualquer projeto de dados.

---

## Bloco 4 — Dados Estruturados x Não Estruturados | 2:30 – 3:30

Outro conceito importante é o tipo de dado com o qual trabalhamos.

Dados estruturados são organizados, geralmente em tabelas, como planilhas e bancos de dados relacionais. São fáceis de processar e analisar.

Dados não estruturados não têm um formato fixo. Textos de e-mail, imagens, vídeos, áudios, publicações em redes sociais. Eles representam cerca de 80% de todos os dados gerados no mundo e analisá-los exige técnicas mais avançadas.

A Ciência de Dados trabalha com os dois tipos.

---

## Bloco 5 — Onde é Aplicada? | 3:30 – 4:30

Ciência de Dados está em praticamente todos os setores.

Na saúde, algoritmos analisam exames e auxiliam no diagnóstico de doenças.

No varejo, sistemas de recomendação sugerem produtos com base no histórico de compras, exatamente o que a Amazon e o Mercado Livre fazem.

Em finanças, modelos identificam transações suspeitas em tempo real para prevenir fraudes.

No marketing, dados de comportamento do usuário permitem anunciar para a pessoa certa, no momento certo.

Onde há decisão a ser tomada e dados disponíveis, Ciência de Dados pode ser aplicada.

---

## Bloco 6 — Encerramento | 4:30 – 5:00

Resumindo: Ciência de Dados combina estatística, programação e negócio para transformar dados em decisões. Aprendemos a diferença entre dado, informação e conhecimento, e vimos que os dados podem ser estruturados ou não estruturados.

Na próxima aula, vamos ver como um projeto de Ciência de Dados é estruturado, do problema inicial até a entrega dos resultados. Te vejo lá.
