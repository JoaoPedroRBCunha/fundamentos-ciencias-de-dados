## 📌 1. Descrição Geral do Projeto

O projeto consiste no desenvolvimento de um módulo educacional introdutório focado em **Fundamentos de Ciência de Dados e Linguagem Python**.

O objetivo central é capacitar a comunidade externa com noções básicas de programação aplicada à análise de dados, utilizando uma abordagem prática e progressiva.

O **Módulo 1** servirá como base teórica e técnica para os módulos subsequentes da disciplina.

## 📚 3. Estrutura do Módulo

**Nome do Módulo:**
➡️ Módulo 1: Fundamentos de Ciência de Dados e Linguagem Python

### 🎯 Objetivos de Aprendizagem

* Compreender o conceito de Ciência de Dados e suas etapas
* Dominar a sintaxe básica da linguagem Python
* Utilizar estruturas de controle e dados
* Desenvolver funções para automação de tarefas

### 📖 Conteúdos Abordados

* Introdução à Ciência de Dados
* Variáveis e Tipos
* Operadores
* Estruturas Condicionais
* Laços de Repetição
* Listas, Tuplas e Dicionários
* Funções

---

## 🔄 4. Sequência dos Conteúdos

1. **Introdução**: O que é Ciência de Dados e por que usar Python
2. **Primeiros Passos**: Variáveis, tipos de dados (`int`, `float`, `str`, `bool`) e operadores
3. **Lógica de Programação**:

   * Condicionais: `if / else`
   * Repetição: `for / while`
4. **Manipulação de Dados**:

   * Listas, Tuplas, Conjuntos e Dicionários
5. **Modularização**: Funções
6. **Conclusão**: Importância da base sólida
